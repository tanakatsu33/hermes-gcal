# Privacy Policy — hermes-gcal

Last updated: 2026-11-17

## What this app is
hermes-gcal is a personal, single-user tool operated by K T for his own scheduling. It is not a public service and has no other users.

## Data accessed
With the owner's consent, the app accesses Google Calendar data only:
- calendar list and free/busy information,
- event details on the owner's own calendars,
- creating events the owner has approved.

Scopes used: `calendar.readonly` and `calendar.events`. The app does not access Gmail, Drive, contacts, or any other Google service.

## How data is used
Data is used solely to check the owner's availability across his own calendar accounts and to create events he approves. Data is not sold, not shared with third parties, and not used for advertising or analytics.

## Storage and retention
OAuth tokens are stored in the owner's private agent profile. Calendar data is processed at request time and is not kept in a separate database.

## Revocation and deletion
The owner can revoke access at any time from Google Account → Security → Third-party access, which immediately stops all access. Stored tokens can be deleted on request to the contact below.

## Contact
Owner/operator: K T (the account holder operating this tool).
