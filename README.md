# hermes-gcal

Personal tool for K T: connects his own Google Calendar accounts (multiple domains he owns/uses) to his personal Hermes agent, so the agent can check availability across calendars and create events he approves.

- Access is limited to Google Calendar (read availability/events, create events).
- Data is used only for the owner's own scheduling. Nothing is sold or shared with third parties.
- Tokens are stored only in the owner's agent profile and can be revoked at any time from the Google account's third-party access page.
